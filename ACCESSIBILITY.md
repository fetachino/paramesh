# Accessibility

ParamMesh aims to make its documentation, examples, and operator dashboard usable by as many people as practical, including people using assistive technology or keyboard navigation.

## Current scope

The repository provides text-based documentation and command-line workflows. The operator dashboard is a web interface, but it has **not** undergone a formal accessibility audit or been certified to meet WCAG conformance requirements. Some charts, real-time status updates, focus behavior, or visualizations may present barriers.

## Reporting accessibility barriers

Please open a GitHub issue using the feature request template, describe the affected page or workflow, the accessibility barrier, your browser and assistive technology if relevant, and a suggested improvement. Do not include private health information, credentials, or sensitive data. If the report involves a security vulnerability, follow [SECURITY.md](SECURITY.md) instead.

## Improvements

Accessibility fixes are welcome through pull requests. Priorities include semantic controls, visible keyboard focus, readable contrast, text alternatives for meaningful graphics, and status information available without relying on color alone.

This statement describes project intent and known verification limits, not a guarantee of accessibility conformance.
