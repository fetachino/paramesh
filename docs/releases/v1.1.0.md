# ParamMesh v1.1.0

This document records the post-v1.0 usability release. The Python package is
published through PyPI Trusted Publishing from immutable tag `v1.1.0`, which
points to merged main commit
`e5abaebeade0e22dd9c5cc66a4ff2ae9483c5b1d`.

## User-facing additions

- Install the packaged local evaluator as `paramesh-local` without Docker once
  the package is published.
- Run the documented external PyTorch examples for the supported linear, small
  CNN and small transformer workload families.
- Compare synchronous, asynchronous and bounded-staleness modes with the
  reproducible benchmark runner and raw artifacts.
- Follow the coordinated checkpoint-abort/resume recovery walkthrough.

## Supported boundary

The package remains a CPU-focused evaluator for Python 3.12 and the documented
float32 workload contract. Arbitrary PyTorch models, GPU training, native ARM64
hardware, high availability and universal performance claims remain outside
this release.

## Publication verification

The manual [`publish-python.yml`](../../.github/workflows/publish-python.yml)
workflow ran successfully as `42406474933` from the exact `v1.1.0` tag. It
checked that the tag matched `pyproject.toml`, built from `uv.lock`, and
published through the registered PyPI Trusted Publisher using GitHub OIDC. The
public wheel was then verified in an isolated environment with:

```powershell
python -m pipx install "paramesh[train]"
paramesh-local --help
```

No PyPI token belongs in the repository or GitHub Actions. The official GitHub
Release remains a separate publication decision.
