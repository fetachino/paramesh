## Inclusion rules

An entry may be added only after the evaluator has used the [independent evaluator
protocol](../../adoption-evaluation.md) and returned the [sanitized feedback
template](../../adoption-feedback-template.md). Use a pseudonym or project label,
not a person's identity. Keep the original private conversation or logs outside
Git; commit only the summarized fields needed to compare onboarding outcomes.
